아이디어 한 문장 시작

양식을 먼저 채울 필요가 없습니다. 만들고 싶은 것을 평소 말하듯 적으면 VCC가 아이디어를 해치지 않는 범위에서 핵심 경험·기능·첫 버전·실행 구조를 먼저 제안합니다.

아이디어를 적으면 VCC가 틀에 끼워 맞추지 않고 구현 방향을 제안합니다.

Open Creator의 기준

먼저 상상하고, 필요한 만큼만 구조화합니다.
아이디어를 기존 양식에 맞추지 말고, 핵심 경험이 무엇인지 먼저 찾은 뒤 첫 버전을 작게 완성합니다.

VCC의 목적은 정답이 정해진 프로그램만 만드는 것이 아니라, 사용자가 머릿속에 가진 독특한 생각을 실제로 움직이는 첫 버전으로 바꾸도록 돕는 것입니다. 업무도구는 그중 하나의 사용 방식입니다.

Python 엔진은 무엇을 계산하나요?

화면과 버튼은 HTML·JavaScript가 담당하고, 요청서 분석·업무 진단·실행 구조 추천은 브라우저 안에서 실행되는 Python(Pyodide)이 계산합니다. 입력한 내용은 분석을 위해 외부 서버로 전송하지 않습니다. 처음 열 때 Python 실행 파일을 내려받지 못하는 내부망 환경에서는 기본(JavaScript) 모드로 동작하며, 실제 업무도구 설계에서는 필요에 따라 단일 HTML·Python 포터블·PWA·로컬앱 구조를 구분해 제안합니다.
  • 입력 항목 인식: "학교명, 예산액, 추진율…"에서 항목을 뽑아 형식(텍스트·금액·비율·날짜·예/아니오 등)과 필수 여부를 판단합니다.
  • 규칙 해석: 확인 규칙을 필수값·중복·값 비교·기준값·형식·기한 등으로 분류하고 R01, R02… 번호와 오류/주의/안내 등급을 붙입니다.
  • 모호함·모순 찾기: 기준 숫자가 없는 규칙, "저장 없음"인데 백업 기능을 요구하는 경우, 민감 분야에 실명 항목이 있는 경우 등을 알려 줍니다.
  • 예시 데이터·검수 시나리오: 규칙을 일부러 어기는 가상 데이터 행을 만들고, 각 행에서 어떤 결과가 나와야 하는지 시나리오로 적어 줍니다.
  • 개인정보 자동 감지: 전화번호·주민등록번호·이메일·계좌번호 형태가 입력칸에 있으면 경고합니다.
